## Cómo ver la maqueta

Abrir `web-page-layout/index.html` en el navegador (no necesita internet: Bootstrap, íconos y fuente están incluidos).
En la pantalla de inicio de sesión se elige el rol (gerente/asistente, vendedor o administrador) para recorrer sus pantallas.
